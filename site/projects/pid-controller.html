2D PID Motion Controller

A feedback controller for a simulated vehicle that must move toward depth and horizontal position setpoints while respecting actuator limits.

ROS 2Closed-loop controlPython
← Back to all projects

Problem statement

A vehicle does not move directly to a target because commands are affected by inertia, buoyancy, delay, and actuator limits. The controller must continuously compare the requested position with the measured position and correct the error without producing unsafe thrust.

How it works

The node subscribes to current depth, current x position, and both setpoints. Every 50 ms it calculates proportional, integral, and derivative terms for each axis. The depth channel adds a bias to counteract simulated buoyancy. Both commands are clamped to the simulator's permitted range before publication.

setpoint - measurement\n→ proportional + integral + derivative\n→ buoyancy compensation (depth)\n→ thrust saturation\n→ simulator

Why it matters in robotics

Feedback control is the foundation of stable motion. The same reasoning applies to underwater vehicles, mobile robots, arms, and drones. A controller that works only at one operating point is not enough. It must expose gains, sample time, sign conventions, and output limits so that it can be tuned against the physical system.

How I build it

I keep the control loop small and explicit. State arrives through ROS topics. The update interval is fixed and visible. Separate state, setpoint, error accumulation, and actuator output make the behaviour easy to inspect. The depth bias and output saturation preserve the real-world details that a purely mathematical PID example would omit.
